SSH klíč místo hesla

Krok za krokem návod pro Windows a PowerShell - jak vygenerovat SSH klíč a přihlašovat se na školní server bez zadávání hesla.

Princip

Na tvém počítači vznikne dvojice klíčů, které spolu matematicky souvisí:

Tvůj počítač

Vygeneruje se pár klíčů. Privátní zůstává doma, veřejný putuje na server.

privátní klíč
veřejný klíč

Server (vpslab.cz)

Veřejný klíč se uloží do ~/.ssh/authorized_keys. Při přihlášení ověří, že máš odpovídající privátní klíč.

Privátní klíč nikdy neopouští tvůj počítač a nikomu ho neposíláš - volitelně ho chráníš heslem (passphrase). Veřejný klíč naopak nahraješ na server a sám o sobě k ničemu nevede.

Mimochodem: místo příkazu ssh lze použít i program PuTTY a soubory se kopírují příkazem scp, taky z PowerShellu.

1 · První přihlášení heslem

Ověříme, že účet funguje - přihlásíš se klasicky heslem a uvidíš uvítací banner VPSLabu.

ssh jmeno.prijmeni@vpslab.cz

Zadej heslo → objeví se uvítací banner. Pak se odhlas:

exit

2 · Vygenerování klíče

Tenhle krok děláš na svém počítači, ne na serveru - vytvoří se dvojice klíčů typu ed25519.

ssh-keygen -t ed25519 -C "jmeno.prijmeni@vpslab.cz"
Pozor: -C musí být velké C - je to jen popisek klíče. Malé -c znamená něco jiného a skončí to chybou Too many arguments.

Cestu k souboru potvrď Enterem (výchozí C:\Users\<uživatel>\.ssh\id_ed25519).

Passphrase je volitelná: chrání klíč, i kdyby ti ho někdo ukradl, ale budeš ji pak zadávat při každém připojení.

3 · Kontrola, že klíče vznikly

ls $env:USERPROFILE\.ssh

Měly by se objevit id_ed25519 (privátní) a id_ed25519.pub (veřejný). Obsah veřejného klíče zobrazíš takto:

Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub"

4 · Nahrání veřejného klíče na server

Varianta A - jedním příkazem

Pošle veřejný klíč rovnou na server a připíše ho do authorized_keys. Naposledy se ještě zeptá na heslo.

Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub" | ssh jmeno.prijmeni@vpslab.cz "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Varianta B - ručně přes schránku

Zkopíruj veřejný klíč do schránky:

Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub" | Set-Clipboard

Přihlas se heslem a na serveru vytvoř složku .ssh:

mkdir -p ~/.ssh
chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys

V nano vlož klíč pravým tlačítkem myši, ulož Ctrl+O → Enter, zavři Ctrl+X. Pak:

chmod 600 ~/.ssh/authorized_keys

5 · Kontrola na serveru

cat ~/.ssh/authorized_keys

Musí tam být řádek začínající ssh-ed25519 AAAA.... Volitelně ověř, že SSH server běží:

sudo systemctl status ssh

Stav musí být active (running).

6 · Přihlášení klíčem - bez hesla

ssh jmeno.prijmeni@vpslab.cz

Nebo s výslovným určením klíče:

ssh -i "$env:USERPROFILE\.ssh\id_ed25519" jmeno.prijmeni@vpslab.cz

Pokud se server nezeptá na heslo (max. na passphrase), máš hotovo.

Časté chyby

ssh-copy-id: příkaz neexistuje

Na Windows tento pomocný nástroj není - je jen pro Linux/macOS. Použij variantu A nebo B z kroku 4. Spouštět ho na serveru nedává smysl, klíč je na tvém PC.

%USERPROFILE% nefunguje

To je syntaxe CMD. V PowerShellu vždy používej $env:USERPROFILE.

id_rsa.pub vs. id_ed25519.pub

Klíč typu ed25519 se jmenuje id_ed25519.pub, ne id_rsa.pub (to je starší RSA).

Could not resolve hostname / Permission denied

Většinou překlep v uživatelském jméně nebo adrese - zkontroluj jmeno.prijmeni@vpslab.cz. Pozor: při špatném jméně server klíč „přijme" a stejně nakonec chce heslo - vypadá to, že klíč nefunguje, ale problém je jinde.

authorized_keys je soubor, ne příkaz

Nikdy ho nespouštěj jako program - otevírej ho přes nano nebo prohlížej přes cat.

Ladění: ssh -v

Ukáže podrobný průběh připojování - který klíč se nabízí a jak server odpovídá:

ssh -v jmeno.prijmeni@vpslab.cz

Bonus

Kopírování přes scp

scp .\index.html jmeno.prijmeni@vpslab.cz:~/web/
scp jmeno.prijmeni@vpslab.cz:~/web/index.html .

Rychlé připojení skriptem

Soubor edulab.bat (Windows) / edulab.sh (Linux):

ssh jmeno.prijmeni@vpslab.cz

Alias v ~/.ssh/config

Host edulab
    HostName vpslab.cz
    User jmeno.prijmeni

Pak stačí: ssh edulab

VS Code - Remote-SSH

Nainstaluj rozšíření Remote-SSH a připoj se na jmeno.prijmeni@vpslab.cz - VS Code použije stejný klíč a otevře vzdálenou složku jako lokální projekt.

Bezpečnostní upozornění

Privátní klíč nikdy nikam nekopíruj ani neposílej - ani kamarádovi, ani do e-mailu, ani na GitHub. Je to jediná věc, která chrání tvůj účet.

Na VPSLabu běží účty všech spolužáků na jednom stroji - vše je logované. Útok na server nebo na účty spolužáků znamená okamžitý konec přístupu k účtu.
